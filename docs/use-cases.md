# Use Cases — TaskFlow

## Действующие лица

- **Гость** — неавторизованный пользователь
- **Client** — клиент, управляет своими проектами и задачами
- **Admin** — администратор, видит всё, управляет пользователями
- **Система** — автоматический актор (cron, уведомления)

## Соглашение

- ⭐ MVP — входит в минимальный продукт (20 из 60)
- Формат: `UC-NN [MVP?] Как <роль>, я хочу <действие>, чтобы <ценность>`
